# renderer/panels

React 面板：设置、调试台，以及以后的猫咪之家、挑片台。

M1 页面通过 `window.ttcats`（`PanelsBridge`）发送命令并接收快照，不能自行修改存档状态。

开发时在面板地址后加查询参数选择页面：

- `?panel=settings`：五项 M1 设置（默认页面）。
- `?panel=profile&cat=<猫id>`：猫咪包里的资料和性格参数；年龄按快照日期计算足岁。
- `?panel=debug`：召唤、睡觉、显示隐藏、播放片段及版本、模拟互动、桌面层崩溃，以及存档和画面状态。

主进程打开窗口、隐藏快捷键和桌面层上报的启停由 #28 集成。直接在普通浏览器打开时没有 preload 桥，会显示中文提示。没有初始快照或猫咪包时不显示可操作的设置。

存档状态以主进程快照为准；两个滑块只保留当前快照版本对应的本地显示草稿，让拖动在等待确认时跟手，收到新版本快照后改用主进程值。其他控件不做预先更新。先订阅再获取初始快照，所有来源都按 `revision` 丢弃旧值及重复值。关闭页面时取消订阅。中文文字集中在 `zh.panels`。

保留根节点的 `placeholder` 测试标记，兼容现有的启动冒烟测试；节点内容已替换为实际面板。

组件验证：`npx vitest run src/renderer/panels/App.test.tsx`（在 `app/` 运行）。测试用假的桥和通过 schema 的猫咪包，覆盖命令、快照乱序、初始读取竞态、资料卡和调试状态。
