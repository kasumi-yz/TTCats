# renderer/panels

React 面板：设置、调试台，以及以后的猫咪之家、挑片台。

页面通过 `window.ttcats`（`PanelsBridge`）发送命令、接收快照和程序状态，不能自行修改存档状态。

开发时在面板地址后加查询参数选择页面：

- `?panel=settings`：设置（默认页面）。按"猫咪、声音、勿扰和隐藏、显示、程序"分标签页，窗口不会太长；底部固定放"导出诊断信息"。
- `?panel=profile&cat=<猫id>`：猫咪包里的资料和性格参数；年龄按快照日期计算足岁。
- `?panel=debug`：单只猫的召唤、睡觉、显示隐藏、播放片段、模拟互动、喵叫呼噜；整体的一键隐藏、重新入场、模拟全屏、开机静默、勿扰、快进时钟；拍照、导出诊断、检查更新、重启并更新；以及存档、勿扰和声音、程序状态、桌面层画面状态。

文件：

- `App.tsx`：连接桥、按 `revision` 收快照和程序状态，选择页面。
- `SettingsPanel.tsx`、`DebugPanel.tsx`、`ProfilePanel.tsx`：三个页面。
- `ShortcutField.tsx`、`shortcut-keys.ts`：录入一键隐藏快捷键（按 `event.code` 认键，校验规则用 `shared/accelerator.ts`）。
- `controls.tsx`：滑块、时刻、开关；`format.ts`：给人看的时刻和状态说明。

存档状态以主进程快照为准；滑块和安静时段的时刻只保留当前快照版本对应的本地显示草稿，让操作在等待确认时跟手，收到新版本快照后改用主进程值。其他控件不做预先更新。先订阅再获取初始值，快照和程序状态都按 `revision` 丢弃旧值及重复值。关闭页面时取消订阅。中文文字集中在 `zh.panels`。

程序状态（版本、自动更新、快捷键注册结果、显示器）拿不到时，设置和调试台照常可用，相关位置显示中文说明，之后收到推送再显示。快捷键格式不对时只在页面上提示、不发命令；格式对了才发 `settings/update`，注册成没成看 `AppStatus.hideAllShortcut`。

保留根节点的 `placeholder` 测试标记，兼容现有的启动冒烟测试；节点内容已替换为实际面板。

组件验证：`npx vitest run src/renderer/panels`（在 `app/` 运行）。测试用假的桥和通过 schema 的猫咪包，覆盖每个设置项和调试按钮发出的命令、勿扰、快捷键录入和错误提示、更新状态、显示器选择、快照和程序状态乱序、初始读取竞态、资料卡。
