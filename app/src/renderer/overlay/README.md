# 桌面层渲染

正式 index.html / index.ts 使用 core/stage，通过正式 OverlayBridge 收集输入并传送事实。

- PixiJS 8 透明 WebGL 画布限 30fps，requestVideoFrameCallback 的 mediaTime 决定实际视频帧并更新纹理。
- 用实际帧的落脚锚点对齐位置和点击遮罩，不以计划帧代替显示帧。
- StageFrame 决定片段、版本、位置、缩放、镜像、纵深、速度、气泡和特效；渲染层不规划下一行为。
- 每只猫缓存当前片段及最近两段。加载中的条目受保护，可临时超出三段，完成后淘汰最久未用条目。
- 新片段未就绪时将旧视频停在最后一帧；过渡片段被打断、且新片段仍从旧片段的开始姿势播放时，改停首帧，避免先跳到结束姿势。画面及点击遮罩沿用旧片段的镜像；加载完成时纹理和镜像一起切换，按最新 clipTimeMs 校正。过期请求不能抢回画面。报错带猫 id 和文件名。
- 暂停时停止 ticker 和视频并保留缓存；绘制帧不再包含某只猫时释放其资源，迟到的加载也必须释放。
- 每 50ms 按当前画面续租约，不使用 mouseleave。拖动用 pointer capture，主进程 dragCancel 兜底丢失的松手事件。
- 鼠标移动只在命中状态变化时立即发送 hover，同一状态内的续租交给定时器。点击按最后一帧的绘制顺序从前往后判断，纵深相同也和画面一致。
- 气泡按猫复用文字和圆角白底，仅文字变化时重新排版和调整底板；按实际视频帧的落脚锚点把气泡放在片段画面顶部。特效按 id 复用，只更新位置、缩放和透明度；结束时销毁。
- ghost 由主进程决定时长；半透明时不新增互动，已开始的拖动继续。

缓存策略按 #25 在 2026-10-01 的最新评论执行，覆盖 ADR-0002 尚未更新的“当前及下一片段”措辞。按 PR #47 的审查建议补上提前打断过渡时的首帧例外；其他不匹配的硬切仍由 StageFrame 的 cut 小特效覆盖，观感需 #7 真实片段复测。

接线与验证见 ../../main/overlay/README.md。test-driver 只供固定位置的窗口与输入链路验收，不由正式入口导入；默认性能测量使用真实 core/stage。

## 声音（#61）

- `audio.ts` 消费 `StageFrame.sounds`，只通过 `ttcats-content://` 读取文件，解码结果按猫和文件缓存。呼噜循环，停止时淡出 150ms；喵叫只播放一次。
- 音量和开关使用快照设置。`silencedBy` 非空、一键隐藏、桌面层暂停、猫被隐藏或离开画面时，取消未完成的加载请求对应的播放，并停止已有声音。恢复时不补播暂停期间的提示。加载完成超过 1 秒的声音也丢弃。
- AudioContext 首次需要声音时创建；加载期间和全部声音结束后挂起，退出时关闭。不为声音增加轮询定时器。
- `StageDebugReport.audio` 上报实际播放中的声音和音频挂起状态，暂停时也继续更新。声音按钮及报告的面板展示归 #62；安静时段、勿扰和开机静默的判定归 #58，正式接线和整体验收分别见 #66、#69。
- `gen-test-pack` 生成 WAV 提示音（两种高音代表喵叫，低音代表呼噜），并给这两类片段设置第 6 帧开始声音。它们是合成测试素材，不代表真实猫叫。

验证：`npm run check`、`npm run build`、`npm run test:smoke`。声音冒烟测试通过正式命令、内容协议和 Web Audio，使用 Electron 的 `isCurrentlyAudible()` 确认声音输出，检查调试报告、开关、全屏暂停和隐藏后的挂起；这不能代替用户听感确认。

人工试听可运行 `npx electron app --test-content --settings`，按 Ctrl+Shift+F10 打开调试台，选择测试猫的 `meow` 片段点击播放，随后点击模拟撸猫听低音呼噜。#62 的声音按钮接好后也可直接调用 `debug/sound`（喵叫一次，呼噜三秒）。

声音空闲性能专项：先构建，在没有其他 Electron 或素材工厂运行时执行 `npx tsx app/e2e/audio-perf.ts`。脚本在首次出声前、播放呼噜并挂起后，各预热 15 秒并采样 30 秒；持续检查独占、窗口可见和音频挂起，结果写入 `app/out/audio-perf/`。可传 `--seconds=300` 延长采样。CPU 口径沿用整应用性能脚本，全部进程的整机百分比相加；两阶段平均值都须低于 2%，前后差异用于检查空闲开销。这项短测不能代替 #69 的整体性能验收。
