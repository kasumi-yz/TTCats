# 拍照（#63）

托盘「拍照」和既有 `photo/take` 命令共用 `createPhoto().take`。菜单位于「截图里是否显示猫」之后。桌面层隐藏、无可用猫、安全模式、加载中或正在拍照时禁用；命令入口做相同检查。托盘在窗口 show/hide 和设置变化时刷新。

照片保存到 `app.getPath('pictures')/TTCats/`，PNG 文件名包含本地日期时间和 UUID，并使用独占创建避免覆盖。保存后通过 Electron 44 的异步 `ClipboardItem` 写入 PNG；复制成功后才发送 #52 定义的 `photo` 消息。快门闪光、缩略图飞向右上角并淡出共 1.5 秒，无声音、不改变窗口焦点或鼠标租约。2 秒忙碌保护拒绝重复拍照，避免拍入上一张的动画。

## 捕获方案

本机实测直接临时关闭截图隐身再调用 `desktopCapturer`，得到完整尺寸的桌面但缺少猫。因此采用 #63 允许的合成方案：临时保护桌面层，等桌面合成器刷新后采集屏幕，再用 `webContents.capturePage()` 取得透明桌面层并按预乘透明度合成。无需新增共享接口、渲染进程消息或依赖。保护状态由桌面层模块在 `finally` 恢复到最新设置；采集期间的设置更新不会提前解除保护。

按窗口实际位置选显示器，整屏物理尺寸由显示器 DIP 尺寸乘缩放率得到。窗口工作区相对整屏的偏移也转换成物理像素。采集尺寸不符或桌面层在捕获时隐藏、关闭、移动，均报中文错误而不生成成功照片。部分 Windows 后端返回空 `display_id`；仅在一块显示器且唯一屏幕来源时使用该来源，多屏无法对应时明确失败。

截屏或保存失败写中文日志并发静音系统通知，不打开抢焦点的错误对话框。剪贴板失败的通知明确告诉用户照片已保存及其路径。
