# 诊断信息导出（D13，#64）

处理 `diagnostics/export`：弹出保存对话框（默认桌面，文件名 `TTCats-诊断-<本地日期>-<时间>.zip`），
把下面这些打成一个 zip，完成后在资源管理器里选中文件；失败时弹中文提示并写日志。

| 文件           | 内容                                                                                               |
| -------------- | -------------------------------------------------------------------------------------------------- |
| `说明.txt`     | 每个文件是什么、时间戳的格式、做了哪些隐私替换                                                     |
| `logs/*`       | 日志目录下的全部文件（`main.log` 及轮转的 `main.log.N`）                                           |
| `save.json`    | 磁盘上当前的存档原文；没有存档时不放，说明里写明                                                   |
| `version.json` | 程序、Electron、Chromium、Node 版本，`isPackaged`（是不是安装版）                                  |
| `system.json`  | Windows 版本和构建号、CPU、内存、`app.getGPUInfo('basic')`、每块显示器、桌面层所在显示器、系统语言 |
| `content.json` | 内容目录、加载的猫和片段数、被停用的猫咪包及中文原因、是否安全模式                                 |

## 隐私

用户目录、用户名、CPU 型号和系统版本由 `platform` 层的 `readSystemInfo()` 提供（硬性规则 3），
导出模块只拿来用；用户目录和用户名只用于替换，不写进压缩包。不收集电脑名，不放截图和照片。

`bundle.ts` 的 `redact` 对所有文本统一处理：

1. 当前用户目录换成 `%USERPROFILE%`。分隔符按"任意个 `\` 或 `/`"匹配，所以日志 JSON 编码后的
   `\\`、`file:///C:/Users/...`、`%20` 写法都能替换。只在完整路径组件处替换：后面必须是 Windows
   文件名不允许的字符（`\ / : * ? " < > |`）、换行或文本结尾，所以 `C:\Users\Ann` 不会抢先匹配 `C:\Users\Anna`。
2. 兜底：其他 `X:\Users\<名字>`（包括 8.3 短名 `NAME~1`、带空格和中文的名字），以及第 1 步分不清边界的写法，
   从 `Users\` 后一直换到上面那些字符或行尾为止，整段变成 `<用户名>`。宁可多换，也不留下半个名字。
   `Public`、`Default`、`Default User`、`All Users` 保留。
3. 用户名换成 `<用户名>`，不区分大小写。前后是英文字母、数字或下划线时不算（`ann` 不换 `anna`）；
   中文句子没有空格，中文用户名紧挨着汉字也会换掉。

## 写文件

在用户选的目录里排他创建（`wx`）一个本次独有的临时文件 `.<文件名>.<随机>.tmp`，写完再改名成用户确认过的目标。
目录里原有的文件（包括同名的 `*.tmp`）不会被覆盖；失败时只删除本次创建的临时文件。

## 入口

- 主进程：`index.ts` 在 `registerIpcRoutes` 里注册 `createDiagnosticsExport(...)` 返回的处理函数。
  安全模式下照常可用（安全模式会就地过滤内容目录，导出的就是停用后的状态）；退出过程中拒绝；导出中重复命令被忽略。
- 安全模式提示框：恢复模块的 `exportDiagnostics` 选项，按钮排在最前并作为默认按钮。
- 设置窗口底部按钮和调试台按钮由 #62 做，都只发 `diagnostics/export`。

## 验证

`diagnostics.test.ts` 用假的 Electron 对象检查文件齐全、各种路径写法和用户名被替换、停用包及原因、
取消、退出中拒绝、写入失败提示和重复命令。隐私替换按原文、JSON 转义、引号、句末、空格、中文名、
前缀相同的账户分别有反例；写文件覆盖了同名临时文件保持不变和改名失败时的清理。冒烟测试通过面板桥发命令导出到临时目录并解压核对，
安全模式那条测试核对提示框按钮和导出的停用结果。
