# core/game

需要存档的规则，在主进程里运行。M1 只管理设置和猫的显示列表；事件、需求和亲密度等到对应阶段再加。

接口：`src/shared/core-api.ts` 里的 `GameCore`。入口是本目录 `index.ts` 导出的 `createGameCore`。

调用方传入已校验的内容和存档。状态改变后，调用方负责存档并推送快照；`stageCommands` 交给桌面层执行，`problems` 是命令被拒绝的中文原因。M1 没有随时间变化的状态，互动事实不改变存档。

停用或缺失的猫保留在设置、快照和导出的存档中；只向已加载且显示中的猫发送桌面层命令。初始存档、设置补丁、快照和导出状态均不共享内部设置的可变引用。
