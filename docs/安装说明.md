# TTCats 安装说明

目前是 Windows 小范围测试版，应用名暂时叫 TTCats，使用默认图标。正式猫咪片段还在制作：豆豆缺少片段时不会出现，日志会记录猫咪包被停用；安装包不包含开发用的测试猫咪包。

## 下载和安装

从开发者给你的 GitHub 下载链接获取 `TTCats-Setup-0.2.x-x64.exe`，不要下载源码压缩包。此阶段尚未发布正式 Release，也没有自动更新。

仓库 Actions 页面里 `main` 分支那次运行的 `TTCats-Windows-installer` 构件供开发者自己试装（PR 的运行不再生成安装包），需要登录 GitHub，下载后解压，构件只保留 7 天。亲友请使用开发者提供的安装包链接，不必从 Actions 下载。

Edge 下载时可能提示这个文件“通常不会下载”。先确认文件来自开发者提供的仓库，再点下载项旁的“…” → “保留” → “显示更多” → “仍然保留”；不同版本的文字可能略有区别。没有保留入口或来源不确定时，请联系开发者，不要关闭浏览器或 Windows 的安全保护。

双击安装包，按中文界面提示安装。只安装到当前 Windows 用户，不需要管理员权限；不用右键选择“以管理员身份运行”。安装完成后，桌面和开始菜单里都有 TTCats 快捷方式，双击即可启动；程序运行时会出现在系统托盘（可能在任务栏右侧的隐藏图标中）。

如果安装或卸载时程序还在运行，按提示先从托盘菜单退出 TTCats，再继续。

## Windows 提示“已保护你的电脑”

TTCats 没有购买代码签名，Windows 可能在第一次运行安装包时显示 SmartScreen 提示。确认文件来自开发者给你的仓库后，点“更多信息”，再点“仍要运行”。如果没有该按钮，请联系开发者，不要关闭 Windows 安全保护。

## 数据和升级

存档、设置和日志放在 `%APPDATA%\TTCats`。可以把这个地址粘贴到资源管理器的地址栏查看；备份时先退出程序，再复制整个文件夹到别处。

以后拿到新版安装包，先退出程序，再运行安装包覆盖安装即可。覆盖安装会保留数据；静默卸载也会保留数据。

## 卸载

先从托盘菜单退出 TTCats，再在 Windows“设置 → 应用 → 已安装的应用”（Windows 10 为“应用和功能”）里找到 TTCats，选择卸载。

卸载时会问“要不要同时删除存档和日志”：

- 选“否”（默认）：只卸载程序，保留数据，以后重装可以继续使用。
- 选“是”：同时删除 `%APPDATA%\TTCats` 里的数据，无法靠重装找回。想保留进度，请先备份整个文件夹。

卸载后桌面和开始菜单的快捷方式也会移除。
