# M1 验收清单（测试猫咪包）

M1 的目标：一只猫稳定运行，重启以后状态还在。按 D24，这次用**测试猫咪包**验收：三只"测试猫"是程序画的橙色几何形状（椭圆身体、圆脑袋、两条腿），格式和真实片段完全一样。豆豆的真实片段做好后，另外复验画面效果，不在这份清单里。

大部分检查已经由自动测试做完（见最后一节），**你只需要做下面 8 步，约 10 分钟**，看"看起来、用起来对不对"。

## 准备

在仓库根目录（比如 `C:\TTCats`）运行，会先构建再启动：

```bash
npm run start:test-pack -w app
```

- 启动后屏幕底部出现 3 只测试猫，任务栏右下角出现一个蓝色小方块托盘图标。
- 存档放在临时目录里，不会影响以后的真实存档。
- 如果前台开着全屏游戏或全屏视频，猫会按设计藏起来，先把它们最小化。

## 逐项检查

每项后面的"✅ / ❌"由你填。哪一项不对，记下看到了什么就行，不用自己找原因。

| # | 怎么做 | 应该看到 | 结果 |
|---|---|---|---|
| 1 | 什么都不做，看 1 分钟 | 三只猫会自己站、坐、走动、偶尔睡觉；换动作时没有明显的闪烁、跳位或残影 | |
| 2 | 打开一个记事本打几个字，然后**单击**一只猫，再接着打字 | 猫有反应、头上冒出气泡；字照样打进记事本，记事本没有失去焦点 | |
| 3 | 鼠标在一只猫身上**左右来回划**几下，然后停住 | 猫开始呼噜、冒出爱心；停下不动约 1 秒后结束 | |
| 4 | 按住一只猫**拖起来**，在空中晃一晃再松手 | 拖着时猫悬空跟着鼠标走；松手后落到地上 | |
| 5 | **右键**一只猫，选「查看资料卡」 | 弹出菜单有：叫它过来、让它睡觉、暂时隐藏它、查看资料卡；资料卡显示这只猫的名字和性格 | |
| 6 | 把记事本窗口拖到猫后面，**按住 Ctrl**，在猫身上点一下 | 按住 Ctrl 时猫变半透明，点击穿过猫、点进了后面的记事本；松开 Ctrl 约 2 秒后猫恢复不透明 | |
| 7 | 按 **Ctrl+Shift+F10** 打开调试台，选一只猫，依次点「睡觉」「模拟单击」「模拟拎起」「模拟放下」「隐藏」「显示」 | 桌面上那只猫依次：睡下、有反应、被拎到空中、落地、消失、出现；调试台"桌面层画面状态"里的姿势和行为跟着变 | |
| 8 | 右键托盘图标 →「设置」，把「大小」调到 125%、「活跃度」改成「安静」；再右键托盘 →「退出」，然后重新运行上面的启动命令 | 设置窗口里改的值立刻生效（猫变大）；重新启动后，大小和活跃度还是刚才改的值 | |

全部 ✅ 就算 M1 验收通过。做完以后关掉 TTCats（托盘 →「退出」）。

## 已经由自动测试覆盖、不用手动做的

- **真实桌面交互测试**（`npm run interaction-test`，在笔记本 2880×1800 150%、台式机 3440×1440 100% 和 2560×1440 100% 上分别跑）：用系统级的鼠标键盘模拟真人操作，检查点空白处和猫的腿缝能点到下面的窗口、悬停后点猫 20 次次次都由猫接住、快速移入移出、拖动时甩出猫的范围和桌面层、按住 Ctrl 拖动、两只猫重叠时点哪只、在输入框和记事本里打字时点猫不抢焦点、单击、撸猫、拎起放下、右键菜单不抢焦点、渲染进程卡住时 200ms 内恢复鼠标穿透。
- **性能**（`npm run perf:app`，笔记本独占机器）：正常播放、全部隐藏、全屏时自动隐藏三种状态的 CPU 和内存。
- **冒烟测试**（`npm run test:smoke`）：退出再启动后设置保留、全屏时隐藏、调试台的命令能到达桌面层、连续崩溃后进入安全模式、存档目录不能写时的退出流程。
- **单元测试**（`npm test`）：坐标换算和点击判定（覆盖 D23 的 4 种显示配置）、行为选择、互动判定、存档迁移和备份。

结果见 [M1 验收报告](../验证报告/M1-验收.md)。
