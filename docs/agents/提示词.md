# 提示词速查

给用户复制粘贴用，把 `<编号>` 换成实际的编号。

具体步骤写在同一个文件夹的 `claim-issue.md` 和 `pr-review.md` 里。以后规则变了，改那两个文件就行，这里的提示词不用动。

## 做 issue

**让 AI 做指定的 issue**：新开一个会话，发：

```text
按 docs/agents/claim-issue.md 认领并完成 issue #<编号>。
```

**让 AI 自己挑一个 issue 做**：新开一个会话，发：

```text
按 docs/agents/claim-issue.md 自己挑一个能做的 issue，认领并完成。
```

**收到审查意见后，让作者修改**：回到写这个 PR 的会话，发：

```text
PR #<编号> 收到了审查意见，按 docs/agents/claim-issue.md 的"收到审查意见"一节处理。
```

**中途不做了**：发给正在做这个 issue 的会话：

```text
issue #<编号> 先不做了，按 docs/agents/claim-issue.md 的"放弃认领"一节撤销认领。
```

**PR 合并以后**：回到写这个 PR 的会话，发：

```text
PR 已经合并了，按 docs/agents/claim-issue.md 的"PR 合并以后"一节收尾。
```

## 审查 PR

Claude 写的 PR 交给 Codex 审，Codex 写的交给 Claude 审。

**审查一个 PR**：新开一个会话，发：

```text
按 docs/agents/pr-review.md 审查 PR #<编号>。
```

**一次审几个 PR**（最多三个，而且都得是另一方写的）：新开一个会话，发：

```text
按 docs/agents/pr-review.md 依次审查 PR #<编号1>、#<编号2>。
```

**作者改完以后复查**：回到审查的那个会话，发：

```text
作者改完了，按 docs/agents/pr-review.md 的"复查"一节复查 PR #<编号>。
```
