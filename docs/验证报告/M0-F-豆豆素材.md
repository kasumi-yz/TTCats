## 本轮比例纠正与实测

`pr71-review/scale-correction.json`：派生片段联合裁剪高 **437**，旧 display_height **256** 对应编码比例 512/437=1.171625；正确值 round(437×150/270)=**243**，比例486/437=1.112128，目标300/270=1.111111。原 land 裁剪高461、display_height256约1.110629。原片与派生片段缩放差来自导出参数，不归咎于 H3 体型变化。

旧 finalize 移至同任务 `finalize-before-pr71-review`，旧 runtime/媒体快照在 `pr71-review`；不覆盖用户已认可的v6证据。新导出 **704×486、48fps、43帧、0.895833秒、无音轨**。共享遮罩编码逐字节不一致数0，ClipSchema/CandidateManifestSchema通过；归一化1024画布遮罩同样0不一致，115412字节正式遮罩/352256字节归一化遮罩。

实际 Electron/Pixi 页面事件录屏：2899帧、58.69fps、最长采样间隔0.081秒；深浅×站坐四组半途返回和完整落地流程4/4，按住/触发未升高/半拎/悬空静止轮廓16/16，边界变化全部0px、不穿地。量测来自录屏JPEG最大连通猫身，不依赖nose/scruff日志。页面事件是实际渲染录屏，不替代 Windows 物理输入；旧v6真实鼠标24/24、真实屏幕12/12不被改写成本轮新物理测试。
