# 素材制作手册 v1

提示词与画面规格来源：GitHub #7，更新于 2026-10-01T18:03:45Z。

## 一、画面规格（所有姿势帧和片段共用）

| 项目     | 规定                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 画布     | 1344×768 像素，PNG，sRGB。H3 也按 1344×768 生成（脚本默认值）                                                                                                                                                                                                                                                                                                                                                                                            |
| 背景     | 整幅纯色 **#38828C**（RGB 56,130,140），取自即梦视频的背景，去掉了原来的暗角和地面渐变。不能有地面线、渐变、阴影、道具、文字                                                                                                                                                                                                                                                                                                                             |
| 朝向     | 正侧面，猫朝右（`facing: right`）。朝左由程序镜像                                                                                                                                                                                                                                                                                                                                                                                                        |
| 镜头     | 机位在猫肩膀的高度，长焦感，没有透视变形，机位固定                                                                                                                                                                                                                                                                                                                                                                                                       |
| 大小     | 站姿时耳尖到脚底 **270 像素**（误差 ±5）。其他姿势按"头一样大"对齐：眼睛中心到鼻尖的距离和站姿帧相差不超过 3%                                                                                                                                                                                                                                                                                                                                            |
| 地面线   | 落地的姿势（站、坐、睡、伏低），脚底都在 **y = 690**                                                                                                                                                                                                                                                                                                                                                                                                     |
| 后脚位置 | 落地的姿势，**近侧（离镜头近的一侧）后脚的脚趾肉垫中心**都在同一个 x 上，以站姿帧为准。站着时后脚只有脚趾着地；坐、睡、伏低时整只后脚掌从脚跟到脚趾都贴在地上，这时只看最前面的脚趾肉垫，不看脚跟。对齐方法：把姿势帧和站姿帧各取 50% 透明度叠成一张图比较，误差不超过 3 像素，不对就只做水平平移。后脚被尾巴挡住看不清时，按脚的轮廓估计，并写明是估计的。锚点的 x 坐标记为 **Xh**，已经按站姿帧定为 **588**，idle-stand 也已按它导出，以后不再改这个数 |
| 悬空     | 身体竖直下垂，近侧后脚的脚尖在 y = 640，x 和站姿帧近侧后脚脚趾肉垫的 x 相同；后颈被拎住的点是最高点                                                                                                                                                                                                                                                                                                                                                      |
| 光线     | 柔和均匀的棚拍光，从正前方略偏上打来，和即梦视频一致；各个姿势之间不能变                                                                                                                                                                                                                                                                                                                                                                                 |

为什么这么定（写给以后的会话）：

- **270 像素**：悬空时整只猫竖着约 520～620 像素，刚好装得进 768 高的画面。游戏里 100% 缩放时猫站着约 150 像素高（D13），素材比它大，显示时更清晰。
- **纯色、无阴影**：素材工厂抠图时要填背景色（`--background 56,130,140`），背景越均匀，毛边越干净。阴影由程序自己画。
- **后脚对齐**：素材工厂导出时，会把每一帧都按落脚锚点对齐（`tools/asset-factory/src/asset_factory/export.py`），导出后整段片段只有一个锚点。换片段时，前一段的锚点和后一段的锚点对齐。所以所有姿势必须用同一个锚点规则，才不会跳位。
  - 规则定为"**后脚着地点**"，具体看近侧后脚的脚趾肉垫。坐下、躺下、站起来、落地时，后脚基本都不挪，挪的是前脚，所以这个点在所有过渡里都自然地保持不动。注意前脚挪的距离并不小：坐下、站起时前脚要前后挪差不多一个身长，要分几步走（2026-10-02 补充）。

## 三、姿势帧

### 3.1 站 `pose-stand.png`（从即梦视频截取，不用 GPT 画）

1. 把即梦视频（752×560，60fps）逐帧导出。挑出**四只脚都踩在地上、腿最接近竖直、前后两对腿各自略微分开**的 3 帧，拼成对比图给用户挑一张。
2. 如果用户觉得这 3 帧都还在迈步，就用 3.6 的"站姿改腿"提示词只改腿。改前、改后并排给用户确认。
3. 用素材工厂的同一个 BiRefNet 模型把猫抠出来，背景色填 `56,130,140` 去色边。**缩小到 0.85 倍**（耳尖到脚底约 270 像素），贴到 1344×768、#38828C 的画布上：脚底对齐 y = 690，整只猫水平居中。
4. 记下 Xh（锚点的 x 坐标）和眼睛中心到鼻尖的距离。后面的姿势按眼鼻距离统一大小，按第一节"后脚位置"和站姿帧横向对齐。（已完成：Xh = 588）

走路还要两张首尾帧，把 `pose-stand.png` 里的猫整体水平平移，不缩放、不改动：

- `pose-stand-walk-start.png`：猫的最左边（尾巴尖）离画面左边 24 像素。
- `pose-stand-walk-end.png`：猫的最右边（鼻尖）离画面右边 24 像素。

### 3.2 GPT 生图的统一做法

- 用 `$imagegen` 生图，参考图按这个顺序传：
  1. `pose-stand.png`：定大小、光线、视角、背景。
  2. `40355B96…`：脸、眼睛、项圈最清楚，可以先把头部裁出来。
  3. `07A80BE2…`：全身毛色、尾巴。
  4. `1808642297…`：脸、尾巴尖。
- 选横版画幅，每个姿势一次出 4 张候选。
- 出图后**不直接用**，统一这样处理：
  1. 抠出猫。
  2. 按"头一样大"缩放：眼睛中心到鼻尖的距离和站姿帧一致。
  3. 贴到 1344×768、#38828C 的画布上，按第一节的规定定位。
  4. 和站姿帧比，如果明显更清晰或更模糊，就轻微模糊或锐化，让观感一致。
  5. 拼成对比图（左边站姿帧，右边 4 张候选，同一缩放比例）给用户挑。
- 每张图都记素材档案：提示词原文、参考图、尺寸、第几次生成、生成时间。

每个生图提示词的开头都加上下面这段 **[STYLE]**，原样替换：

```
Photorealistic still frame from a high-quality 4K nature video, matching image 1 exactly in camera angle, lighting, color grading, fur rendering and the size of the cat. Natural fur texture, no illustration look, no 3D-render look, no over-sharpening. Exact side view (profile) with the cat facing right, camera at the cat's shoulder height with a long lens, no perspective distortion. Soft, even, diffused studio light from the front and slightly above. The whole background is one perfectly flat, uniform color #38828C (RGB 56, 130, 140): no floor, no horizon line, no gradient, no vignette, no shadow, no props, no text. Only one cat in the image. The whole cat is visible with empty space on every side; nothing is cropped. The cat in this image is the same individual cat as in all reference images.
```

## 四、H3 片段

### 4.1 统一参数和写法

- 命令：`uv run python queue_clip.py --first <首帧> --last <尾帧> --prompt "<提示词>" --seconds <秒数> --seed <种子>`。其他参数用默认值：1344×768、24fps、20 步。
- 每个提示词依次用 4 个种子：**6、42、1234、2026**。
- H3 的工作流没有反向提示词，所以提示词里尽量写"要什么"，少写"不要什么"。
- H3 会顺带生成声音。声音用不上，所以提示词结尾统一写安静的环境音。
- 每个提示词开头加 **[SHOT]**，结尾加 **[END]**，原样替换：

[SHOT]：

```
A static, locked-off camera films a real cat from the side against a plain studio backdrop of one flat teal color. The framing never changes: no zoom, no pan, no camera shake, no cuts. The cat is a golden shaded British cat with a plush coat, a narrow ivory collar and a dark-tipped tail, facing right.
```

[END]：

```
Photorealistic, real-time natural speed, the same soft even lighting throughout, and the backdrop stays perfectly flat and empty. Only this one cat is in the frame. Quiet room tone.
```

### 4.2 第一批：初筛用（按 D8，先做这两段）

**idle-stand（站着待机）**：首帧、尾帧都用 `pose-stand.png`，`--seconds 5`

```
[SHOT] The cat stands quietly on all four paws in the same spot for the whole shot, relaxed and calm. Its belly rises and falls with slow breathing, it blinks slowly once, one ear twitches, it glances a little upward and then back to the front, and the tip of its tail sways gently. All four paws stay planted exactly where they are; the cat does not take a step. At the end it is back in exactly the same pose as at the start. [END]
```

**walk（走路）**：首帧 `pose-stand-walk-start.png`，尾帧 `pose-stand-walk-end.png`，`--seconds 5`

```
[SHOT] The camera stays still while the cat walks across the frame from left to right. It starts standing still on the left, then sets off in a slow, relaxed, unhurried stroll, heavy-bodied and steady, head level and tail held low and relaxed. Each paw is set down firmly and stays fixed on the ground while the body moves over it. It walks at an even pace for about three strides, then slows down and stops on the right, standing still on all four paws. [END]
```

walk 说明：

- 用"机位固定、猫从左走到右"，不用"原地走"。这样脚是实实在在踩在地上的，素材工厂按锚点的位移算出步速，游戏里按这个速度平移，脚就不会打滑。豆豆体型敦实，慢悠悠地走也符合它的样子。
- 素材工厂取中间匀速走的一段做循环。循环的起点选**最像站姿的那一帧**，这样停下来接 idle-stand 时跳得最少。
- 如果 4 个种子都不行，再试下面的备选写法（首帧、尾帧都用 `pose-stand.png`），也是 4 个种子：

```
[SHOT] The cat walks to the right at a slow, relaxed, steady pace while the view smoothly follows it from the side, so the cat stays in the middle of the frame and the plain backdrop shows no movement. It starts standing still, walks for about three even strides, then slows down and stops, standing still on all four paws. [END]
```

备选写法下猫是原地走的，步速只能这样量：踩在地上的那只脚，每秒往后滑多少像素。量出来的值写进报告。

### 4.3 第二批：动作链（初筛通过以后再做）

**开跑前先做对齐检查**（2026-10-02 新增，不用显卡）：`pose-sit.png`、`pose-dangle.png` 是按旧写法定位的。生成本节的片段之前，先按第一节"后脚位置"把它们各和 `pose-stand.png` 叠图检查一次：

- 叠图上，在站姿帧近侧后脚脚趾肉垫中心画一条竖线。叠图存进素材库，报告里写上路径。
- 记下两张图近侧后脚（悬空帧看脚尖）的 x 和站姿帧差多少像素。超过 3 像素就只做水平平移改正，不缩放、不上下移、不改画面；改之前的版本留档，素材档案写明平移了多少。
- 坐姿帧另外记一个数：前脚要往后挪多少像素，即站姿帧近侧前脚的 x 减去坐姿帧近侧前脚的 x。只记录，不用改。
- 只是平移，不用再给用户挑。

**stand-to-sit（站→坐）**（2026-10-02 第 2 版，为什么改见本条末尾）：首帧 `pose-stand.png`，尾帧 `pose-sit.png`，`--seconds 5`

写法 A，4 个种子：

```
[SHOT] The cat is standing, then slowly sits down on the same spot. The toes of both hind paws stay pressed to the floor on exactly the same spot from start to finish. First its hind legs fold: the hocks bend down to the floor just behind the hind paws, and its rump lowers backward and down until it rests on the floor right behind them. Next, as its weight shifts back and its chest rises, it walks its front paws backward in a few small steps, one paw at a time, until they stand together just in front of its hind paws. Last, it sweeps its tail forward low along the floor, around its body, until it curls in front of its front paws; the tail stays long, thick and plumed the whole time, and its dark tip comes to rest next to the front paws. Slow and natural, about three seconds in total; then the cat sits still, upright and calm. [END]
```

- 初筛第 5 条按第五节的量法：近侧后脚的脚趾肉垫全程不离地、x 变化不超过 3 像素；前脚每一步从落地到抬起都不打滑。
- 片段开头和结尾的静止部分，在素材工厂确认时用裁剪区间裁掉，各留 0.3 秒左右。

**A 的 4 个种子都不合格时，不用停，直接做备选 B**：插一张中间帧，分两段生成再接起来。

B-1. 用 3.2 的统一做法生成一张**中间帧** `pose-sit-half.png`：屁股已经坐到地上，四只脚还在站姿的位置。它只给 stand-to-sit 用，不是姿势帧，不用给用户挑，由 AI 按下面的要求挑。参考图按 3.2 的顺序传，再加 `pose-sit.png` 作为第 5 张：

```
[STYLE]
[DOUDOU]
Pose: Doudou is halfway through sitting down. All four paws are on exactly the same spots as in image 1. Its hind legs are fully folded with the hocks resting on the floor, and its rump already rests on the floor just behind the hind paws, like the hindquarters in image 5. Its front legs are still straight but lean back at a slant, so the body slopes up from the rump to the raised chest. Head level, looking straight ahead to the right, ears relaxed, eyes open, mouth closed. The tail lies relaxed on the floor behind the body, its dark tip visible. The head is exactly the same size as in image 1.
```

- 定位：近侧后脚的脚趾肉垫和站姿帧对齐（±3 像素）。
- 挑选：近侧前脚和站姿帧近侧前脚相差不超过 20 像素；屁股贴地；头的大小和站姿帧一致；长相按 3.2 的要求。
- 4 张都不合格就再出 4 张。两轮都没有合格的，B 算失败。

B-2. 第一段：首帧 `pose-stand.png`，尾帧 `pose-sit-half.png`，`--seconds 4`，4 个种子：

```
[SHOT] The cat is standing, then lowers its hindquarters to sit down on the same spot. The toes of all four paws stay pressed to the floor on exactly the same spots from start to finish. Its hind legs fold, the hocks bend down to the floor just behind the hind paws, and its rump lowers backward and down until it rests on the floor; its front legs stay straight and lean back as its body tilts up. The tail stays relaxed on the floor behind it. Slow and natural, about one and a half seconds; then the cat holds still in this half-sitting position. [END]
```

B-3. 第二段：首帧 `pose-sit-half.png`，尾帧 `pose-sit.png`，`--seconds 4`，4 个种子：

```
[SHOT] The cat is half sitting on the floor, then settles into an upright sit on the same spot. Its rump and the toes of both hind paws stay on exactly the same spots from start to finish. Its chest rises as it walks its front paws backward in a few small steps, one paw at a time, until they stand together just in front of its hind paws. Then it sweeps its tail forward low along the floor, around its body, until it curls in front of its front paws; the tail stays long, thick and plumed the whole time, and its dark tip comes to rest next to the front paws. Slow and natural, about two seconds; then the cat sits still, upright and calm. [END]
```

B-4. 两段各挑一个合格的，接成一段 stand-to-sit：

- 第一段裁掉结尾的静止部分；第二段开头如果有静止，也裁掉；接缝处重复的那一帧只留一份。
- 接缝处停顿不超过 0.3 秒，画面没有跳变。
- 用无损或接近无损的方式接（例如 `-crf 10` 以下重新编码），不要音频。接好的 MP4 再交给素材工厂。
- 另写一份素材档案，写明两段原始视频的档案、各自保留的帧范围、接法，ingest 时用它作为 `--generator-log`。

B-2、B-3 各有至少 1 个种子合格，并且接起来合格，B 才算成功。B 也失败时，按总原则停下来，把 A 和 B 的失败画面一起整理好，请用户转给 Claude。

**和其他片段的关系**：idle-sit、dangle、land 不依赖 stand-to-sit 的结果。做完对齐检查以后照常按顺序生成，不用等 stand-to-sit 过关；stand-to-sit 的 A、B 都失败时，也先把它们做完，再一起汇报。此前被中断的 idle-sit 种子 6 重新提交，不计入质量失败。

为什么这么改（写给以后的会话）：

- 第 1 版用 4 个种子都是后脚先往前迈一步再坐下，0/4 合格（证据在素材库 `work\issue-7\claude-prompt-handoff\`）。
- **可能原因一：首尾帧本身对不上**。站着时后脚只用脚趾着地，坐着时整只后脚掌从脚跟到脚趾都贴在地上。旧规格只写了"后脚着地点"，没说看脚趾还是脚跟。如果坐姿帧是按脚跟或脚掌中间对齐的，坐姿帧里的脚趾就比站姿帧靠前，模型只能让后脚往前迈。所以先做对齐检查，并在第一节写死"看近侧后脚的脚趾肉垫"。
- **可能原因二：旧提示词把前脚要挪的距离说小了**。后脚不动的话，前脚要从肩膀下方一路挪到后脚跟前，差不多一整个身长；旧提示词却写"前脚往后挪一点"，和首尾帧对不上，模型就用自己习惯的办法（后脚往前凑）来补。新写法把动作拆成"先蹲下屁股、再分几步收回前脚、最后绕尾巴"，每一步都用正面的说法写清楚。对齐检查里记下的前脚挪动距离，可以用来判断这一条。
- 尾巴改成"贴着地面往前扫"，并写明尾巴一直又长又蓬、尾尖是深色。旧写法下尾巴往前转时，尾尖被画成一团黑，或者深色消失。
- 时长从 4 秒改成 5 秒，给前脚分步挪留出时间；多出来的静止部分在素材工厂里裁掉。
- 备选 B 用中间帧把"后脚不动、屁股先落地"固定在中间时刻，两段各只做一件事，模型更难自作主张。代价是多一张生图和 8 次生成，接缝处可能有很短的停顿。

## 五、AI 初筛清单（每段视频都要查，查完再给用户看）

每秒至少抽 4 帧，逐项写"过 / 不过 / 原因"：

1. **首尾**：第一帧和最后一帧都和对应的姿势帧一致，没有突然跳变。
2. **镜头**：背景四个角的颜色不变，画面不推拉、不平移、不抖动（walk 备选写法除外）。
3. **身份**：全程是同一只猫，不会变脸。项圈、深色的尾巴尖、绿眼睛、毛色一直都在。
4. **结构**：每一帧都是四条腿、一条尾巴；腿没有粘在一起、互相穿过或多出来。
5. **脚**：后脚按提示词该不动的时候，位移不超过 3 像素。量的是近侧后脚的脚趾肉垫：全程不离地，x 变化不超过 3 像素；脚跟落地、后脚掌放平是正常动作，不算位移。walk 里，以及坐下、站起时前脚分步挪的时候，每只脚从落地到抬起，相对地面不动。
6. **干净**：没有出现手、人、道具或文字，也没有阴影或地面线。
7. **速度**：动作快慢自然，不像慢动作，也不像快进。
8. **循环**：循环片段的最后几帧能顺滑地接回第一帧。

不合格的只记录，不给用户看。4 个种子里有合格的，就拼成对比图给用户挑。

## 六、交给素材工厂时的设置

- `matte` 的 `--background` 一律填 `56,130,140`。
- **落脚锚点**（都按"后脚着地点"的规则，不要直接用工具建议的值。工具的建议按轮廓底部算，会随身体起伏变化，导出后猫在游戏里会滑）：
  - **原地的片段**（idle-stand、idle-sit、sleep、stand-to-sit、sit-to-stand、sit-to-sleep、sleep-to-sit、land）：每一帧都用同一个点 (Xh, 690)。
  - **walk**：每一帧取"后脚着地点"跟着猫移动的位置：后半身正下方的地面点，匀速段要平滑。步速按它的位移计算。
  - **dangle**：每一帧取后脚尖的位置，同时逐帧标出关键点 `scruff`（后颈被拎住的点）。拖动时程序让 `scruff` 跟着鼠标走；松手后程序把猫往下移，直到锚点碰到地面，再接 land。这是本 issue 对 #24 的建议，要在报告里写明，由 #24 和 ADR-0002 定稿。
- `speed`：原地的片段写 0；walk 写上面算出来的值。
- `keypoints`：每一帧标出鼻尖 `nose`，看不见的帧写 null；dangle 另外标 `scruff`。
- **`display_height` 不能都填 150**。导出画面的高度是按每段片段自己的裁剪范围定的。要让猫在所有片段里一样大，每段都要按"站姿 270 像素 = 显示 150 像素"换算：
  - `display_height = round(该片段按锚点对齐后的联合裁剪高度 × 150 ÷ 270)`。
  - 联合裁剪高度的算法和 `export.py` 一样：所有帧主体的联合边界，上下各加 2 像素。可以先导出一次读出画面尺寸，再用正确的值重新导出。
  - 这个用法容易出错，在报告里建议给素材工厂加一个"每个原始像素对应多少显示像素"的选项。
