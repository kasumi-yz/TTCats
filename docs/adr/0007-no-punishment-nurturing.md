# 养成不设惩罚：猫不会生病、不会离家出走、不会死

这几只猫是用户家里真实的猫。数字版的它们如果"生病"或"死掉"，会让人难受，也会让养成变成负担。所以：

- 需求（饱腹、心情、精力）只影响猫的行为。
- 离线期间按真实时间结算，但最多只算 12 小时。最差的状态就是"很饿、很想你"。
- 用户回来时，触发"久别重逢"。

## Considered Options

- **像 QQ 宠物那样会生病**：最有怀旧感。但写实风格画不出病容，而且对用户的情感伤害太大。
- **离线期间时间冻结**：最轻松。但就没有了"它们一直在等你"的感觉。
