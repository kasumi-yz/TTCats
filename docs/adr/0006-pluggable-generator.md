# 素材工厂的"生成"步骤可以替换；先半手动，再逐步自动化

AI 视频模型更新得很快。本地模型（MiniMax H3、Wan 2.2 14B 首尾帧工作流）和在线工具各有取舍，所以素材工厂把"生成"做成可以替换的第一步，有三种来源：

- 本地 ComfyUI
- 在线工具的 API
- 手动把视频放进收件箱

后面的处理步骤都和用哪种生成器无关，包括：抠图、去色边、原地化、找循环点、测步速、编码。

**先半手动**：第一版（v0）里，裁剪区间、循环点、落脚锚点、步速都由人来确认；哪一步被证明稳定可靠了，再把它改成自动。

**素材档案**：每个片段都必须在素材档案里记下具体用的模型文件和工作流版本，不能只写"Wan 2.2"这样的名字。同一个名字底下，不同版本的能力和所需资源差别很大。
